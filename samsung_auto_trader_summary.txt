1. Prompt interpretation
CODEX.md의 핵심 요구사항은 한국투자 Open API 기반, 모의투자 전용, REST만 사용, 토큰 재사용, 호출 수 최소화, 안정성 우선, 그리고 새 프로젝트 폴더(samsung_auto_trader/)에 모듈형 구조로 구현하는 것이었음.
따라서 구현 방향은 단순 기능 추가가 아니라, 적은 호출 횟수로 장시간 안정적으로 동작하는 자동매매 프로그램을 만드는 쪽으로 설정됨.

2. Folder structure adherence
구현 시 가장 중요한 제약 중 하나는 사용자가 예시한 폴더 구조를 그대로 따르는 것이었음.
이에 따라 samsung_auto_trader/ 아래에 main.py, config.py, auth.py, api_client.py, market_data.py, account.py, orders.py, trader.py, logger.py, requirements.txt, README.md, token_cache.json을 배치하는 형태로 구성함.
즉, 더 나은 구조를 별도로 제안하기보다 프롬프트에서 요구한 구조를 우선적으로 존중하는 방식으로 구현함.

3. Core architecture and resource control
프롬프트의 핵심은 mock trading 환경의 낮은 호출 제한을 고려하는 것이었기 때문에, 통신부와 인증부를 분리하고 토큰 재사용 구조를 중심으로 설계함.
특히 main.py에서 TokenManager를 한 번 생성하고 이를 KisApiClient가 공유하도록 하여, 프로그램 전역에서 같은 토큰을 재사용하도록 구성함.
이 구조는 매 요청마다 인증을 다시 수행하지 않게 하며, 전체 API 사용량을 줄이고, 프롬프트가 요구한 효율적인 자원 사용과 안정성 우선 원칙을 반영한 결과임.

4. Safety-first implementation
속도보다 안정성을 중시하라는 요구에 따라 코드 전반에 보수적 장치를 배치함.
예를 들어 api_client.py에서는 get/post 요청이 모두 공통 _request()를 통과하도록 설계하고, 여기서 try-except, 재시도, 백오프, timeout, API 에러 판별을 처리하게 함.
또한 auth.py에서는 같은 날 발급된 토큰을 token_cache.json에 저장하여 재사용하게 하고, trader.py에서는 거래시간 외 주문을 차단하며, 주문 후에는 잔고 및 체결 상태를 다시 확인하도록 구성함.
이와 같은 Rate limit 대응, 예외처리, 보수적 폴링, 토큰 캐싱, 로그 기록은 모두 mock 환경에서 안전하게 동작하는 프로그램이라는 프롬프트 요구를 충실히 반영한 것임.

5. Trading logic modularization
거래 로직은 프롬프트 기준에 맞춰 현재가를 확인한 뒤 2,000원 아래 매수 주문, 2,000원 위 매도 주문 방식으로 구현함.
중요한 점은 이 로직이 전체 프로그램에 흩어져 있지 않고 trader.py의 실행 루프 내부에 집중되어 있다는 점임.
따라서 이후 전략을 변경하고자 할 경우 run() 내부에서 호출되는 _run_cycle() 또는 이에 해당하는 거래 루프 부분의 몇 줄만 수정하면 충분함.
예를 들어 상승장과 하락장에서 다른 조건을 적용하거나, 차액 폭을 변경하거나, 매수/매도 우선순위를 조정하더라도 전체 구조를 다시 설계할 필요 없이 거래 판단 부분만 수정하면 되도록 구성함.
이는 기능 단위 모듈화라는 요구를 반영한 구현임.

6. Mistake and correction
구현 과정에서 한 가지 분명한 실수가 있었음.
초기 작업에서는 CODEX.md의 새 프로젝트 폴더를 만들라는 요구를 충분히 반영하지 못하고, 프롬프트를 정확히 읽지 않은 상태에서 새 폴더를 만드는 대신 기존 파일에 덮어쓰는 방향으로 작업한 적이 있었음.
이는 요구사항 해석과 작업 범위 확인이 부족했던 실수였음.
이후 해당 문제를 바로잡아 samsung_auto_trader/를 별도 폴더로 구성하고, 기존 저장소 구조를 보존하는 방향으로 정리함.
즉, 최종 결과물은 프롬프트 요구에 맞게 정돈되었으나, 중간 과정에서는 기존 파일을 건드리지 말고 새 폴더에 독립적으로 생성해야 한다는 점을 놓쳤던 시행착오가 있었음.
